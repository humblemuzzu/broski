# Fix Lint Issues

Run the linter and fix all issues in the codebase.

## Steps

1. Run `flutter analyze` to find issues
2. Run `dart fix --apply` to auto-fix
3. Run `dart format .` to format code
4. Report any remaining issues that need manual fixes
